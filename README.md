# Виноваторник

Опиши проблему, и он назовёт виноватого. К твоей проблеме виноватый **никак не относится**.

```
$ python -m vinovatornik "в меня врезался грузовик"
Виноват: Холодильник с характером
Категория: Быт (уровень 3/5, мифический размах)
Уверенность: 67%
Обоснование: Холодильник с характером давно вызывает подозрения у экспертов, которых мы не опрашивали.
```

## Запуск

```
python -m pip install -r requirements.txt
python -m vinovatornik "упал прод"
python -m vinovatornik --level 5 --json "сломался лифт"
python -m pytest
```

## Правила

- Один и тот же ввод всегда даёт одного и того же виновного.
- Ни виновник, ни обоснование не содержат слов из описания проблемы.
- Виноватым нельзя назначить самого пользователя.
- Уровень абсурда от 1 (быт) до 5 (полный абсурд).

Подробности: страницы вики (папка `wiki/`) и список задач в `ISSUES.md`.
