# Роли

Проект выполняет один человек, который по очереди надевает разные «шляпы».

| Роль | Что делает | Где проявляется |
|---|---|---|
| Владелец продукта | расставляет приоритеты в бэклоге | колонка Backlog |
| Разработчик | пишет код и тесты | ветки `feature/*`, PR |
| Тестировщик | ручные проверки перед релизом | чек-лист в [Тестирование и деплой](Testing-and-Deploy) |
| DevOps | CI, раннер, релизы | `.github/workflows/ci.yml` |
| Технический писатель | вики и README | папка `wiki/` |

## Соседние команды (условные)

- **Контент**: поставляет данные.
- **Платформа**: поставляет инфраструктуру.

Подробности зависимостей: [Роадмап](Roadmap).

## Правила работы

1. Меняем одну «шляпу» за раз: например, не пишем код и не ревьюим его в одной сессии.
2. Каждый PR проходит самопроверку по Definition of Done из страницы [Процесс разработки](Process).
3. В In Progress не больше двух задач.
