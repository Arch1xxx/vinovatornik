# Виноваторник

> [!NOTE]
> Учебный проект по дисциплине «Программная инженерия» (РТУ МИРЭА, магистратура). Выполняется одним человеком.

**Виноваторник** принимает описание проблемы и называет виноватого. Виноватый **никак не связан** с проблемой: если в тебя врезался грузовик, виноват будет, например, холодильник с характером.

## Быстрый старт

```bash
python -m pip install -r requirements.txt
python -m vinovatornik "в меня врезался грузовик"
python -m pytest
```

## Пример

```text
Виноват: Холодильник с характером
Категория: Быт (уровень 3/5, мифический размах)
Уверенность: 67%
Обоснование: Холодильник с характером давно вызывает подозрения у экспертов, которых мы не опрашивали.
```

## Принципы

1. Один ввод означает один ответ.
2. Виноватый не связан с вводом.
3. Пользователя обвинять нельзя.
